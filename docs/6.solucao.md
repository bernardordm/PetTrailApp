# 6. Projeto da Solução

Abaixo estão apresentadas as principais telas do sistema PetTrail construído, ilustrando a interface gráfica desenvolvida e as funcionalidades disponibilizadas para os perfis de Tutores e Passeadores, tanto no ambiente mobile quanto no ambiente web.

### Tela Inicial (Mapa e Disponibilidade) - Mobile
![Tela Inicial - Mapa](imagens/Tela%20Inicial%20(Mapa%20e%20Disponibilidade).jpeg)

**Descrição:** Interface principal do aplicativo mobile exibindo o mapa interativo. Permite a visualização da localização atual e conta com um botão centralizado e rápido para o passeador alternar seu status de "Disponível" ou "Indisponível" para receber novas solicitações de passeio.

### Dashboard (Métricas e Desempenho) - Mobile
![Tela de Dashboard](imagens/Dashboard%20(Métricas%20e%20Desempenho).jpeg)

**Descrição:** Painel de controle gerencial mobile, essencial para o passeador acompanhar seu desempenho. Exibe de forma consolidada os ganhos financeiros do mês atual, ganhos totais, distância percorrida acumulada, tempo total de passeios, nota média de avaliações e gráficos de taxa de conclusão.

### Meus Passeios (Histórico) - Mobile
![Tela Meus Passeios](imagens/Meus%20Passeios%20(Histórico).jpeg)

**Descrição:** Tela de listagem mobile contendo o histórico de passeios do usuário. Cada card apresenta um resumo rápido com a foto do pet, nome do tutor, data/hora da solicitação, valor cobrado e o status atual do serviço (ex: "Em andamento", "Concluído").

### Detalhes do Passeio - Mobile
![Tela Detalhes do Passeio](imagens/Detalhes%20do%20Passeio.jpeg)

**Descrição:** Visão detalhada do relatório gerado no aplicativo após a conclusão (ou durante) um serviço. Apresenta os dados do tutor e pet, avaliação recebida (estrelas), métricas exatas de tempo (início/fim/duração), distância percorrida e a renderização do mapa com o trajeto real gravado via GPS.

### Meu Perfil - Mobile
![Tela Meu Perfil](imagens/Meu%20Perfil.jpeg)

**Descrição:** Tela mobile dedicada à gestão das informações do usuário. No caso do passeador, exibe a foto, nome, nota média geral, e permite a edição de dados cruciais como telefone de contato, documento, valor fixo cobrado por passeio e estimativa de tempo médio de cada serviço.

### Meus Pets - Mobile
![Tela Meus Pets](imagens/Meus%20Pets.jpeg)

**Descrição:** Interface mobile dedicada ao perfil do Tutor para o gerenciamento de seus animais de estimação. Permite visualizar os pets já cadastrados (com foto, nome e espécie/raça), além de fornecer opções diretas para editar dados, excluir registros ou adicionar um "Novo Pet" à plataforma.

### Ajustes (Configurações) - Mobile
![Tela de Ajustes](imagens/Ajustes%20(Configurações).jpeg)

**Descrição:** Tela de configurações gerais do aplicativo mobile, permitindo que o usuário personalize a sua experiência de uso, como a seleção da aparência da interface (alternância entre tema Claro e Escuro).

---

### Login e Autenticação - Web
![Login Web](imagens/Login%20Web.jpeg)

**Descrição:** Tela de entrada da plataforma web. Apresenta um design limpo e responsivo, permitindo que tutores e passeadores acessem suas contas usando e-mail e senha. Possui também um link rápido para a criação de novas contas.

### Home / Dashboard do Tutor - Web
![Home Tutor Web](imagens/Home%20Tutor%20Web.jpeg)

**Descrição:** Painel inicial web do perfil Tutor. Oferece uma visão consolidada com acesso rápido aos pets cadastrados e o detalhamento do último passeio realizado, incluindo métricas (duração, distância, valor) e a exibição do mapa estático com a rota percorrida.

### Lista de Passeios - Web
![Lista de Passeios Web](imagens/Lista%20Passeios%20Web.jpeg)

**Descrição:** Interface web de histórico completo de passeios. Organizada em abas (Todos, Finalizado, Recusado), permite que o usuário encontre rapidamente os registros passados, com informações essenciais do pet, tutor envolvido, data e valor.

### Relatórios e Métricas (Passeador) - Web
![Relatórios Web](imagens/Relatorios%20Web.jpeg)

**Descrição:** Dashboard gerencial web aprofundado para o perfil Passeador. Exibe indicadores de performance (KPIs) cruciais, como lucro total, tempo investido, avaliação média e taxa de conclusão de passeios, com filtros de período (Semana, Mês, Personalizado) para análise financeira e profissional.

### Meu Perfil - Web
![Perfil Web](imagens/Perfil%20Web.jpeg)

**Descrição:** Tela web de gestão de conta. Centraliza as informações pessoais e profissionais do usuário, permitindo atualizar a foto de perfil, dados de contato, documento de identificação e ajustar a precificação do serviço (valor e tempo médio).

### Meus Pets - Web
![Meus Pets Web](imagens/Meus%20Pets%20Web.jpeg)

**Descrição:** Tabela web de gerenciamento de animais cadastrados pelo Tutor. Exibe as informações vitais de cada pet (espécie, porte, idade e observações comportamentais) em formato de lista estruturada, com ações rápidas para edição ou exclusão de registros.
