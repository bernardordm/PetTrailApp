# 5. Wireframes

Abaixo estão apresentados os wireframes desenvolvidos para a plataforma web do PetTrail:

### 5.1. Tela de Login
![Wireframe Login](imagens/Wireframe%20Web%20-%20Login.png)

**Descrição:** Estrutura inicial focada no acesso à plataforma. Apresenta um layout dividido em duas colunas, com um espaço reservado para ilustração à esquerda e o formulário de credenciais (e-mail e senha) à direita, acompanhado do botão principal de entrada e link para cadastro.

### 5.2. Home (Visão Tutor)
![Wireframe Home Tutor](imagens/Wireframe%20Web%20-%20Home%20Tutor.png)

**Descrição:** Layout da página inicial estruturado no formato de painel de controle (dashboard) com navegação lateral (sidebar). A área principal exibe cards de acesso rápido no topo (resumo dos pets) e um bloco inferior de maior destaque reservado para as informações e o mapa do último passeio realizado.

### 5.3. Lista de Passeios
![Wireframe Lista de Passeios](imagens/Wireframe%20Web%20-%20Lista%20Passeios.png)

**Descrição:** Interface dedicada à listagem do histórico de serviços. Estruturada com filtros de visualização no topo (Todos, Finalizado, Recusado) e uma lista de cards expansíveis organizados cronologicamente, contendo as informações essenciais e o botão para ver detalhes.

### 5.4. Relatórios e Métricas
![Wireframe Relatórios](imagens/Wireframe%20Web%20-%20Relatorios.png)

**Descrição:** Tela analítica voltada para a exibição de dados e desempenho. Utiliza uma grade superior de cards de métricas (KPIs) como lucro, distância e tempo, seguida por blocos inferiores destinados à renderização de gráficos visuais (como o gráfico de rosca para taxa de conclusão) e resumos numéricos do período.

### 5.5. Perfil do Usuário
![Wireframe Meu Perfil](imagens/Wireframe%20Web%20-%20Perfil.png)

**Descrição:** Estrutura modular para o gerenciamento da conta do usuário. A tela é dividida em blocos lógicos que separam os dados pessoais (com avatar no topo), informações financeiras do serviço e dados de contato/documentação, facilitando a leitura e a edição independente de cada seção.

### 5.6. Gestão de Pets
![Wireframe Gestão de Pets](imagens/Wireframe%20Web%20-%20Meus%20Pets.png)

**Descrição:** Tabela de gerenciamento voltada para a listagem estruturada dos animais cadastrados. Apresenta colunas claras para foto, nome, espécie, porte, idade e observações, finalizando com uma coluna de ações rápidas (ícones de editar e excluir) alinhada à direita.
